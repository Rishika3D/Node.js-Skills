🧪 How to Test

Choose your preferred method to test the API:

Option 1: Test Here (GET endpoints only)

Click "Test Endpoint" buttons above for quick testing

Option 2: Postman (Recommended)

1. Download Postman from postman.com
2. Download the collection: School-Management-API.postman_collection.json
3. Import into Postman
4. Set base_url = https://rishika-school-api.herokuapp.com
5. Run all test requests

Option 3: cURL Commands

# Health check curl https://rishika-school-api.herokuapp.com/health # List schools curl "https://rishika-school-api.herokuapp.com/api/listSchools?latitude=40.7128&longitude=-74.0060" # Add school (requires POST) curl -X POST https://rishika-school-api.herokuapp.com/api/addSchool \ -H "Content-Type: application/json" \ -d '{"name":"School","address":"123 Main","latitude":40.7128,"longitude":-74.0060}'
